Principais Formatações

Negrito / Destaque

Nessa frase temos um termo em negrito usando a tag <b> (Não semântica / Sem sentido, apenas atibui forma)

Nesta frase, tenho um termo em destaque usando <strong> (semântica / Possui um sentido e também atribui forma, significa que é um termo de destaque, este é seu sentido)

Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag <i> (Não semântica)

Nesta frase, temos um termo em itálico usando a tag <em> (Semântica)

Texto Marcado

Podemos criar também um texto marcado com a tag <mark>

Texto grande e Pequeno

Estamos criando um texto grande e um texto pequeno neste parágrafo.

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido mas não deve ser considerado

Texto inserido / Sublinhado

Podemis marcar um texto como inserido para dar uma ênfase e indicar que ele foi adicionado depois, para esse usamos a tag <ins>. (Semântica)

Existe também um sublinhado com a tag <u> (não semântica)
